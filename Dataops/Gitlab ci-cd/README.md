# GitLab CI/CD

Esta sección contiene material práctico para estudiar integración y entrega continuas con GitLab.

## Proyecto disponible

- [`learn-gitlab-app/`](learn-gitlab-app/README.md): aplicación de ejemplo desarrollada con React y Vite, con pruebas unitarias mediante Vitest y pruebas de extremo a extremo mediante Playwright.

La app presenta el tema del curso, pero en este directorio todavía no hay un archivo `.gitlab-ci.yml` que defina un pipeline. Consulta el README de la app para ejecutarla localmente y correr sus verificaciones.
