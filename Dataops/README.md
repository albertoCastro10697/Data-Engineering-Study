# DataOps

Material de estudio y ejercicios relacionados con prácticas de DataOps, automatización y entrega continua para proyectos de datos y software.

## Contenido actual

- [GitLab CI/CD](<Gitlab ci-cd/README.md>): aplicación de práctica React/Vite y recursos para aprender flujos de integración y entrega continua con GitLab.
- `GitLab CICD- pipelines -DevOps/`: carpeta reservada para material adicional sobre pipelines y DevOps.
- `Teoria/`: espacio para apuntes teóricos.

La aplicación actual es un proyecto de aprendizaje. No se encontró una definición de pipeline `.gitlab-ci.yml` en el contenido disponible; por ahora, el repositorio contiene la app y su configuración de pruebas.
