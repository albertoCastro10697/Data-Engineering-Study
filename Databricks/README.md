# Databricks

Material de estudio y práctica con la plataforma Databricks: preparación para la certificación Data Engineer Associate, cursos de Databricks Academy y ejemplos de Databricks Asset Bundles.

## Secciones

- [Cursos](Cursos/Databricks-Certified-Data-Engineer-Associate/README.md): recursos del curso de preparación para **Databricks Certified Data Engineer Associate**, con notebooks, consultas SQL, laboratorios, soluciones, lecturas y exámenes de práctica.
- [Databricks Academy](<Databricks Academy/README.md>): documentos de cursos sobre fundamentos, arquitectura, ingeniería de datos, gobernanza y administración de la plataforma.
- [Databricks Asset Bundles](<Databricks Assets Bundle/README.md>): apuntes sobre configuración de clústeres y un proyecto de ejemplo con targets de desarrollo, staging y producción.

Los proyectos que despliegan recursos necesitan la Databricks CLI, autenticación y acceso al workspace correspondiente. Revisa la configuración de cada bundle antes de desplegarlo.
